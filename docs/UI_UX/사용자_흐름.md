# USER FLOW
## 전체 프레임
좌측에는 3개의 페이지로 이동할 수 있으며 각각
- 검색 페이지: 사용자가 실제로 이용하는 서비스를 제공하는 페이지입니다.
- 데이터 관리: 사용자의 개인화 데이터를 관리하기 위한 공간입니다. Git, Tistory, Local, Notion으로부터 데이터를 가져올 수 있습니다. 각각 설정을 통해 필요한 설정 (API 토큰 또는 검색 대상 폴더 경로)을 할 수 있습니다.
- AI 설정: 사용자가 서비스에 사용할 LLM을 사용할 수 있게 해줍니다. 사용자의 openai api 또는 local llm, ai 서비스 등과 호환 가능하게 설정할 예정입니다.
## [메인] 검색 페이지
기본 페이지로 영역은 크게 검색 섹션(필터), AI 제공 세션, 조회된 문서 섹션(정렬 가능)으로 나누어져있습니다.

사용자가 상단에 입력창을 입력하고 원하는 검색 범위 (날짜와 원천 소스 대상)을 설정하면 일정 시간 뒤에 llm의 응답이 나오며 하단의 조회된 문서 섹션에는 사용자의 질문과 유사도가 높고 후보 대상이 되는 문서들이 제공되게 됩니다.

문서 카드에는 제목, 조회된 chunk, 등록된 날짜, 카테고리가 들어가있으며 url 또는 경로를 통해 사용자가 해당 문서의 위치에 접근할 수 있습니다.

## 데이터 페이지
사용자가 자신의 검색에 사용될 데이터를 설정하는 공간으로 크롤링 대상의 url 또는 git, notion 등에 대한 api 토큰 또는 로컬 폴더 대상 경로들을 등록하고 동기화 버튼(등록된 모든 소스 동기화 버튼 또는 특정 소스 하나만 동기화) 버튼을 이용해서 데이터를 프로그램에 동기화시킬 수 있습니다. 각 카드에는 등록된 문서의 개수, 등록된 문서의 총 크기, 동기화된 날짜, 동기화 상태 등을 확인할 수 있습니다.
